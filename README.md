# SYCHAT

一个面向群聊场景的实时房间协作平台。

## 功能

### 账户
- 手机号注册
- 手机号或用户名登录
- 退出登录
- 获取当前用户信息

### 好友
- 搜索用户
- 发送好友申请
- 查看好友列表
- 查看好友申请列表
- 同意或拒绝好友申请

### 聊天
- 私聊
- 群聊
- 离线消息拉取
- 历史消息拉取
- WebSocket 实时消息收发
- 消息已读确认
- 聊天消息携带视频时间上下文

### 房间
- 创建房间
- 通过邀请码加入房间
- 获取或刷新房间邀请码
- 仅群聊会话内展示一起看入口

### 一起看
- 房间内同步播放视频
- 播放、暂停、快进、快退、拖动进度同步
- 当前共享者独占控制权
- 发起人结束共享后释放控制权
- 其他成员在共享中只能观看和同步

### 视频
- 普通视频文件上传
- 分片上传
- 输入 fileId 加载视频
- 同步视频到房间
- 房间历史视频列表
- 历史视频预览与恢复

### 回放
- 房间历史消息回放
- 房间历史视频记录
- 弹幕回放

### 前端页面
- 登录 / 注册页
- 会话列表
- 好友面板
- 聊天面板
- 一起看面板
